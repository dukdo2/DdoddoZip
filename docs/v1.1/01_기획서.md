## 2. F22 속도 개선

### 지금 상태 (1.0.0, 이 PC에서 측정)
| 항목 | 또또집 | 반디집 |
|---|---|---|
| 1GB 7Z 압축 (빠르게) | 36초 | 27초 |
| 1GB 7Z 풀기 | 7-9초 | 10.5초 |
| 2GB ZIP 풀기 | 23초 | 29초 |
| 작은 파일 5,000개 풀기 | 4.4초 | 4.9-5.5초 |

### 목표
| 항목 | 목표 |
|---|---|
| 압축 (ZIP·7Z, 수준별) | 같은 크기 결과일 때 반디집과 같거나 빠름 |
| 풀기 | 1.0 수준 유지 (느려지지 않음) |
| 큰 TAR.GZ 열기 | 진행률 표시, 취소 가능. 목록만 볼 때는 전체를 풀지 않는 방법 검토 |
| 파일 10만 개 압축 파일 열기 | 창이 멈추지 않음, 3초 이내 목록 표시 |
| 창 뜨는 시간 | 1초 이내 유지 |

### 조사할 것 (2단계 기술 설계에서)
- 압축 수준을 엔진 설정으로 바꾸는 값, 스레드 수, 파일 읽기 방식
- 반디집과 압축 결과 크기를 맞춘 공정한 비교표
- 측정은 다른 작업 없이 따로, 같은 파일로 3번씩

## 3. F23 후원

- 메인 창 오른쪽 위 또는 정보 창에 **[후원하기]** 버튼. 누르면 후원 방법 두 가지를 보여 줌
  - **카카오페이**: 국내 후원 (송금 링크)
  - **GitHub Sponsors**: 해외·카드 후원
- 원칙: 광고·팝업·기능 제한 없음. 후원 여부와 상관없이 모든 기능 무료
- **버튼만 둠**: 첫 실행이나 업데이트 직후에 따로 안내하지 않음
- GitHub 저장소 페이지에도 후원 버튼 표시 (`.github/FUNDING.yml`)
- 후원 계정 만들기와 받을 계좌 연결은 사용자가 직접 진행, 앱에는 링크만 들어감

## 4. F20 자동 업데이트

### 동작
1. 프로그램을 켤 때 GitHub에 최신 버전을 물어봄 (하루 한 번까지)
2. 새 버전이 있으면 메인 창 위에 띠로 안내: "또또집 1.1.1이 나왔습니다 [업데이트] [나중에]"
3. [업데이트]를 누르면 설치 파일을 받고, 파일이 맞는지 확인(해시)한 뒤 설치
4. 설치가 끝나면 또또집이 다시 열림

### 원칙
- **묻지 않고 설치하지 않음**: 항상 사용자가 누를 때만
- 확인하는 곳은 GitHub 공식 저장소(`dukdo2/DdoddoZip`)의 Releases 하나뿐
- 보내는 정보 없음 (GitHub에 "최신 버전이 뭔지" 묻기만 함). 설정에서 끌 수 있음
- 받은 파일은 GitHub가 알려 주는 해시와 같을 때만 실행
- 인터넷이 안 되면 조용히 넘어감
- 우클릭 메뉴(--quickzip 등)로 실행될 때는 확인하지 않음 (빠르게 끝나야 하므로)

### 1.0.0 사용자
1.0.0에는 업데이트 기능이 없어서, 1.1은 직접 받아 설치해야 함. 1.1부터는 자동으로 알림.
