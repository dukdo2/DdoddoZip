## U1 업데이트 알림 띠
- 메인 창 맨 위, 제목줄 바로 아래 한 줄. 빈 화면(S1)과 압축 파일 화면(S2) 모두
- 문구: "**또또집 1.1.1**이 나왔습니다." + [업데이트] [이 버전 건너뛰기] [✕]
- 바탕: 연한 민트(`#E3F5F1`), 왼쪽에 민트 선. 경고처럼 보이지 않게
- [업데이트]: 바뀐 점 창(U4)을 먼저 보여 줌
- [이 버전 건너뛰기]: 이 버전은 다시 알리지 않음
- [✕]: 이번만 닫기. 다음 날 다시 확인

### 업데이트한 뒤 첫 실행
- 같은 자리에 한 번만: "**1.1.1**로 업데이트했습니다." + [바뀐 점 보기] [✕]
- [바뀐 점 보기]: U4를 [확인] 버튼만 있는 형태로 엶

## U4 바뀐 점 창
- 내용은 GitHub 릴리스에 적은 소개글을 그대로 가져옴 (제목·목록·굵은 글씨 정도만 표시, 링크는 글자로)
  - 그래서 릴리스를 올릴 때 "바뀐 점"을 꼭 적어야 함 (아래 작성 규칙)
- 크기: 너비 480, 높이 최대 420 (넘치면 안에서 스크롤)
- 업데이트 전: 제목 "또또집 1.1.1 바뀐 점", 아래에 "설치하면 또또집이 잠시 닫혔다가 다시 열립니다." + [나중에] [지금 업데이트]
- 업데이트 후: 제목 "1.1.1에서 바뀐 점" + [확인]
- 여러 버전을 건너뛰었으면 (예: 1.1.0 → 1.1.2) 사이 버전들의 바뀐 점을 최신부터 차례로 이어서 보여 줌
- 정보 창(A1)의 "1.1.1이 나왔습니다" 옆에도 [바뀐 점] 링크

### 릴리스 소개글 작성 규칙
- 맨 앞에 `## 바뀐 점` 구역을 두고 좋아진 것을 한 줄씩 (`- 압축 속도 최대 2배 빨라짐`)
- 앱은 `## 바뀐 점` 구역만 보여 줌. 구역이 없으면 소개글 전체를 보여 줌

## U2 업데이트 받는 중
- 1.0 진행률 창(S5) 그대로. 제목 "또또집 1.1.1 받는 중", 취소 가능
- 바뀐 점 창에서 이미 설치를 골랐으므로, 다 받으면 따로 묻지 않고 바로 설치 시작
- 관리자 확인(UAC)이 뜨고, 또또집이 닫혔다가 설치가 끝나면 다시 열림

## U3 업데이트 실패
- 1.0 오류 창(S8) 그대로
- 받기 실패: "업데이트를 받지 못했습니다. 인터넷 연결을 확인해 주세요."
- 해시 불일치: "받은 파일이 올바르지 않아 지웠습니다. 잠시 후 다시 시도해 주세요." (자세히: 기대한 값과 받은 값)
- 어떤 경우든 지금 버전은 그대로 동작

## A1 정보 창
- 열기: S2 도구 모음 오른쪽 끝 [정보], S1 오른쪽 아래 "정보" 글자 링크
- 크기: 너비 420, 높이는 내용에 맞춤. 크기 조절 없음

| 구역 | 내용 |
|---|---|
| 머리 | 집 아이콘(64px), "또또집", "버전 1.1.0" |
| 업데이트 | 상태 한 줄 + [업데이트 확인] 버튼 + "자동으로 업데이트 확인" 체크 상자 (기본 켜짐) |
| 후원 | "또또집은 광고 없이 무료입니다. 도움이 되셨다면 후원해 주세요." + [카카오페이로 후원] [GitHub Sponsors] |
| 아래 | GitHub 저장소 · 라이선스 · 문제 신고(메일) 링크, [닫기] |

업데이트 상태 한 줄:
- "최신 버전입니다." (회색)
- "확인하는 중…" (회색, 버튼 잠김)
- "**1.1.1**이 나왔습니다." + [업데이트] (민트)
- "확인하지 못했습니다. 인터넷 연결을 확인해 주세요." (회색)

후원 버튼:
- [카카오페이로 후원]: 카카오페이 노란색(`#FEE500`), 검은 글자. 누르면 브라우저로 송금 링크
- [GitHub Sponsors]: 흰 바탕, 분홍 하트. 누르면 브라우저로 후원 페이지
- 링크가 아직 없는 버튼은 숨김. 둘 다 없으면 후원 구역 전체를 숨김

## S1, S2 바뀌는 곳
- S2 도구 모음 오른쪽 끝: `♥ 후원` `정보` (작은 글자 버튼, 오른쪽 정렬)
- S1 빈 화면 오른쪽 아래: `♥ 후원 · 정보` 작은 링크 (최근 파일 목록 아래)
- [♥ 후원]을 누르면 정보 창이 열리고 후원 구역에 초점
