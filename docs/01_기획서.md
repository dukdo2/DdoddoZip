## 1. 개요

| 항목 | 내용 |
|---|---|
| 이름 | 또또집 |
| 목적 | 개인용으로 시작해 포트폴리오, 지인 무료 배포, 무료 공개 출시까지 고려 |
| 대상 | 윈도우 10/11 (64비트) 일반 사용자 |
| 기술 | C# + .NET 10 (WPF) (2단계에서 .NET 8에서 변경) |
| 공개 | GitHub 공개 |
| 참고 제품 | 반디집, 알집, 7-Zip |

### 지향점
1. **광고·번들 설치 없음**: 무료 압축 프로그램의 가장 큰 불만 해소
2. **한글 파일명 자동 처리**: ZIP 안의 CP949/UTF-8 이름을 자동 감지해서 깨지지 않게 표시
3. **가볍고 빠름**: 실행 1초 이내, 탐색기 우클릭으로 바로 압축/해제
4. **안전한 해제**: 압축 파일이 엉뚱한 경로에 파일을 쓰는 공격(Zip Slip) 차단

## 2. 지원 형식

| 형식 | 압축 | 해제 | 비고 |
|---|---|---|---|
| ZIP | O | O | AES-256 암호 지원 |
| 7Z | O | O | 암호 지원 |
| TAR, GZ, BZ2, XZ (TAR.GZ 등 묶음 포함) | O | O | |
| RAR (RAR4, RAR5) | X | O | RAR 압축은 독점 기술이라 불가 |
| ISO, CAB 등 | X | O | |

## 3. 기능 목록과 우선순위

### P0: 첫 버전(MVP)에 반드시 포함
| 번호 | 기능 | 설명 |
|---|---|---|
| F01 | 압축 파일 열기 | 창에서 압축 파일 내용 목록 보기 (이름, 크기, 압축 크기, 날짜) |
| F02 | 압축 해제 | 전체/선택 해제, "여기에 풀기", "압축 파일 이름 폴더에 풀기" |
| F03 | 압축하기 | 형식 선택, 압축 수준(빠름/보통/최고) 선택 |
| F04 | 끌어다 놓기 | 파일을 창에 놓으면 압축, 압축 파일을 놓으면 열기 |
| F05 | 진행률·취소 | 진행 막대, 남은 시간, 취소 버튼 |
| F06 | 한글 이름 자동 처리 | ZIP 파일명 인코딩 자동 감지, 수동 변경도 가능 |
| F07 | 암호 파일 해제 | 암호 입력 창 |
| F08 | 덮어쓰기 확인 | 덮어쓰기 / 건너뛰기 / 이름 바꾸기 / 모두 적용 |
| F09 | 안전한 해제 | 위험 경로 차단, 260자 넘는 긴 경로 지원 |
| F10 | **우클릭 "ZIP으로 압축하기"** | 탐색기에서 파일/폴더를 하나 이상 선택하고 우클릭하면 "○○.zip으로 압축하기" 메뉴가 나오고, 누르면 창 없이 바로 ZIP 생성 (진행률만 표시) |

> F10 압축 파일 이름 규칙: 하나를 고르면 그 이름(예: `01_기획서.zip`), 여러 개를 고르면 상위 폴더 이름(예: `docs.zip`). 같은 이름이 있으면 `docs (2).zip`처럼 번호를 붙임.

## 4. 품질 기준

| 항목 | 기준 |
|---|---|
| 실행 속도 | 창이 1초 이내에 뜸 |
| 압축 속도 | 7-Zip과 비슷한 수준 (같은 엔진 사용 예정) |
| 대용량 | 4GB 넘는 파일, 파일 10만 개 넘는 압축 파일도 처리 |
| 안정성 | 깨진 압축 파일을 열어도 프로그램이 꺼지지 않고 오류 안내 |
| 화면 반응 | 압축/해제 중에도 창이 멈추지 않음 |

## 5. 라이선스 방향 (2단계에서 확정)
- 압축 엔진은 **7-Zip 엔진(7z.dll)** 사용을 유력하게 검토. 무료 배포·출시 모두 가능한 라이선스(LGPL)이며, RAR 해제 부분은 "RAR 압축 기능을 만들지 않는다"는 조건만 지키면 됨.
- 또또집 자체 코드는 GitHub에 MIT 라이선스로 공개 예정.

## 8. 2단계에서 정할 것
- 우클릭 메뉴 표시 방식: 윈도우 11은 우클릭 시 간단 메뉴가 먼저 뜨고 "더 많은 옵션 표시"를 눌러야 전체 메뉴가 나옴. 첫 화면 메뉴에 바로 띄우려면 설치 방식(패키지 등록)이 달라지므로 2단계에서 방법을 비교해 결정
- 영문 이름 표기 (GitHub 저장소, 실행 파일 이름용. 예: TtoTtoZip, DdoddoZip)
