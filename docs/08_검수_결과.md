## 1. 고친 것

| # | 문제 | 영향 | 고친 방법 |
|---|---|---|---|
| 1 | TAR.GZ·TAR.XZ·TAR.BZ2를 열 때마다 뒤에서 도는 스레드 4개가 남음 (7단계 속도 개선 때 생긴 문제) | 여러 번 열면 메모리가 계속 늘어남 | 쓸 때만 스레드를 만들고, 끝나면 반드시 정리 |
| 2 | 압축 파일에 적힌 크기를 믿고 작은 파일을 메모리에 풀었음 | 크기를 속인 압축 파일로 메모리를 가득 채울 수 있음 | 256KB를 넘으면 바로 디스크로 옮겨 씀 |
| 3 | 뒤에서 파일을 쓰는 스레드가 예상 밖의 오류로 죽으면 풀기가 멈춘 채 끝나지 않을 수 있었음 | 드물지만 프로그램이 멈춤 | 모든 오류를 "이 파일 실패"로 기록하고 계속 진행 |
| 4 | 덮어쓰기로 풀다가 작은 파일 하나가 실패하면, 원래 있던 같은 이름 파일을 지웠음 | 원본 손실 | 실제로 디스크에 쓰기 시작한 경우에만 지움 |
| 5 | 압축할 때 "연결 폴더는 건너뛴다"는 규칙이 OneDrive 폴더에도 걸릴 수 있는 방식이었음 | OneDrive 안의 하위 폴더가 통째로 빠질 위험 (지금 PC의 명령줄 도구에서는 정상이었음) | 진짜 연결 폴더(바로 가기 폴더)만 건너뛰도록 변경, 압축하기 창의 파일 수 계산도 같은 규칙 사용 |
| 6 | 풀 위치에 쓸 수 없어 실패해도 "압축 파일이 손상되어"라고 표시 | 원인을 잘못 알려 줌 | 저장 실패는 "파일 N개를 저장하지 못했습니다"로 따로 안내 |
| 7 | 취소 확인 창이 풀기·검사 중에도 "만들던 압축 파일은 지워집니다"라고 표시 | 문구가 맞지 않음 | 압축과 풀기 경우를 모두 설명하는 문구로 변경 |
| 8 | 확장자가 틀린 7Z·RAR 파일을 열면 ZIP 전용 "파일명 인코딩" 표시가 나올 수 있었음 | 헷갈림 | ZIP일 때만 표시 |
| 9 | 프로그램이 비정상 종료되면 임시 파일이 계속 남음 (TAR.GZ는 수 GB일 수 있음) | 디스크 낭비 | 시작할 때 지난 실행이 남긴 임시 파일 정리 |
| 10 | 파일 수천 개를 선택하고 우클릭하면 메뉴 6개가 각각 전체 목록을 읽음 | 메뉴가 늦게 뜸 | 메뉴 글자와 표시 여부는 앞의 일부만 보고 결정 |
| 11 | 설치 파일이 업데이트 때 묻지 않고 탐색기를 닫는 설정이었음 | 열어 둔 폴더 창이 모두 닫힘 | 닫을 프로그램을 보여 주고 선택하게 함 |
| 12 | 쓰지 않는 다른 나라 언어 파일이 설치 파일에 들어감 | 파일 411개 → 267개, 45.2MB → 44.4MB | 한국어만 포함 |

자동 테스트 61개 통과 (2개 추가: 연결 폴더 건너뛰기, TAR.GZ 반복 열기).

## 2. 속도 확인

| 항목 | 또또집 | 반디집 |
|---|---|---|
| 2GB ZIP 풀기 | 23초 | 29초 |
| 1GB 7Z 풀기 | 7-9초 | 10.5초 |
| 작은 파일 5,000개 풀기 | 4.4초 | 4.9-5.5초 |
| 1GB 7Z 압축 (빠르게) | 36초 | 27초 |

- 7단계 문서의 "5GB ZIP 풀기 314초"는 다른 작업과 겹친 측정이었음. 따로 재면 정상
- 압축은 반디집보다 약 30% 느림. 압축 수준 설정이 서로 달라 정확한 비교는 아님. 다음 버전에서 살펴볼 항목

## 3. 고치지 않고 제안으로 남긴 것

| 우선 | 항목 | 내용 |
|---|---|---|
| 높음 | 인터넷에서 받은 파일 표시 유지 | 윈도우는 인터넷에서 받은 파일에 표시를 붙여서, 실행할 때 경고(SmartScreen)를 띄움. 또또집으로 풀면 이 표시가 사라져 경고 없이 실행됨. 윈도우 탐색기와 반디집은 표시를 이어 줌. 넣으면 풀기가 조금 느려짐 |
| 중간 | 큰 TAR.GZ 열기 | 열 때 안의 TAR 전체를 임시 폴더에 먼저 풀어서, 수 GB짜리는 오래 걸리고 진행률이 안 보임 |
| 중간 | 코드 서명 | 없으면 처음 받는 사람에게 "PC 보호" 경고가 뜸 (유료 인증서 필요) |
| 낮음 | 끌어서 꺼내는 중 다른 버튼 | 작은 파일을 끌어 꺼내는 짧은 순간에 [풀기]를 누르면 같은 압축 파일을 동시에 읽게 됨 |
| 낮음 | 파일 수십만 개 압축 파일 | 목록을 화면 스레드에서 만들어 잠깐 멈춘 것처럼 보일 수 있음 |
| 낮음 | 같은 이름 항목 압축 | 서로 다른 폴더의 같은 이름 파일을 함께 압축하면 압축 파일 안에 같은 이름이 두 개 생김 |
| 낮음 | 개발용 설치 스크립트 | `tools/dev-install.ps1`은 사용자 폴더의 DLL을 PC 전체에 등록함. 개발 PC 전용이고 배포에는 쓰지 않음 |

## 4. 문제없다고 확인한 것
- 위험한 경로 차단: `..`, 드라이브 문자, 예약 이름(CON 등), 끝의 점·공백, `:`(숨은 스트림) 모두 처리
- 압축 엔진(7z.dll)은 설치 폴더의 전체 경로로만 불러옴
- 우클릭 DLL은 메뉴 글자만 만들고 실제 작업은 별도 프로세스에서 실행 (탐색기에 영향 없음)
- 압축은 임시 파일에 쓴 뒤 이름을 바꿔서, 취소·실패해도 깨진 압축 파일이 남지 않음
- 설치 파일로 등록되는 DLL은 Program Files(관리자만 쓸 수 있는 곳)에 있음

## 7. 아직 확인하지 못한 것
- 탐색기가 우클릭 DLL을 쓰는 중에 업데이트하는 경우: 이번에도 탐색기가 DLL을 불러오지 않은 상태라 시험 못 함. 우클릭 메뉴를 한 번 띄운 뒤 설치 파일을 다시 실행하면 확인 가능
- 고친 오류 문구 화면은 직접 띄워 보지 않음
