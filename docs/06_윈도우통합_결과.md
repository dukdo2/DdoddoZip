## 1. 우클릭 메뉴 (F11)

"더 많은 옵션 표시" 메뉴에 선택한 대상에 따라 3개씩 나옵니다.

| 선택한 것 | 메뉴 | 동작 |
|---|---|---|
| 일반 파일, 폴더 | 또또집: ○○.zip으로 압축(D) | 같은 폴더에 ZIP 생성 (5단계와 같음) |
| | 또또집: ○○.7z로 압축 | 같은 폴더에 7Z 생성 |
| | 또또집으로 압축하기... | 압축하기 창(S3)을 열어 형식·이름·수준 선택 |
| 압축 파일만 | 또또집: 여기에 풀기 | 압축 파일이 있는 폴더에 바로 풀기 |
| | 또또집: ○○\ 에 풀기 | 압축 파일 이름의 폴더를 만들어 풀기 (여러 개면 "각각 폴더에 풀기") |
| | 또또집으로 풀기... | 풀기 창(S4)을 열어 위치·덮어쓰기 방식 선택 |

- 압축 파일만 골랐을 때는 풀기 메뉴만, 그 밖에는 압축 메뉴만 나옵니다 (반디집과 같은 방식)
- 압축 파일 여러 개를 골라 풀면 하나씩 차례로 풉니다. 제목에 (1/3)처럼 순서 표시, 취소하면 남은 것도 멈춤
- 암호 파일, 같은 이름 파일, 손상 파일은 메인 창과 똑같이 암호 창·덮어쓰기 창·오류 창으로 처리
- 모든 메뉴에 "또또집" 머리말을 붙여 반디집 메뉴와 구분

### 확인한 것
| 항목 | 방법 | 결과 |
|---|---|---|
| 메뉴 구성 | 탐색기와 같은 방식으로 메뉴 목록 생성 | 텍스트 파일·폴더: 압축 3개 / ZIP 파일: 풀기 3개 |
| 여기에 풀기 | 명령으로 실행 | 파일과 폴더가 압축 파일 옆에 바로 풀림 |
| 폴더에 풀기 (2개 동시) | 명령으로 실행 | `단일\`, `묶음\` 폴더가 각각 생김 |
| 7Z로 압축 | 명령으로 실행 | `가.7z` 생성 |
| 자동 테스트 | 57개 (2개 추가) | 모두 통과 |

## 2. 파일 연결 (F12)

- 압축 파일 우클릭 → **연결 프로그램**에 "또또집"이 나옵니다
- 윈도우 **설정 → 앱 → 기본 앱**에도 "또또집"이 등록됩니다
- 대상: zip, 7z, rar, tar, gz, tgz, bz2, tbz2, xz, txz, zst, iso, cab, wim, lzh, arj
- **기본 프로그램은 바꾸지 않습니다.** 윈도우는 프로그램이 스스로 기본 앱이 되는 것을 막고 있어서, 더블클릭으로 또또집이 열리게 하려면 "연결 프로그램 → 다른 앱 선택 → 또또집 → 항상"을 직접 골라야 합니다
- 또또집을 기본으로 고르면 압축 파일이 또또집 압축 파일 아이콘(흰 종이 + 민트 배지)으로 보입니다
- 형식별로 다른 아이콘(zip용, 7z용 등)은 만들지 않고 공통 아이콘 하나를 씁니다

## 4. 알려진 제약
- **DLL을 바꾸면 탐색기를 다시 시작해야 새 메뉴가 보임**: 설치 파일(7단계)에서는 설치 끝에 안내하거나 자동으로 처리해야 함
- **메뉴 개수**: 반디집이 같이 설치된 PC에서는 압축/풀기 메뉴가 두 벌이 됨. 나중에 설정에서 메뉴를 골라 켜고 끄는 기능을 넣을 수 있음 (P3 후보)
- **"풀기..." 창은 첫 번째 압축 파일 기준**으로 파일 수를 보여 주고, 고른 설정을 나머지에도 똑같이 적용
