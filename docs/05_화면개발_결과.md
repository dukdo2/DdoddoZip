### 메인 창 동작
- 압축 파일 끌어다 놓기 → 열기 / 일반 파일·폴더 끌어다 놓기 → 압축하기 창
- 목록에서 폴더 더블클릭 → 들어가기 / 파일 더블클릭 → 임시 폴더에 풀어서 연결된 프로그램으로 열기
- 목록에서 바탕화면·탐색기로 끌어 놓기 → 그 위치에 풀기
- 아무것도 선택하지 않고 [풀기] → 전체, 선택하고 [풀기] → 선택한 것만 (지금 보고 있는 폴더 기준)
- 파일명 인코딩 메뉴: 자동 / 한국어 / UTF-8 / 일본어 / 중국어 간체·번체 / 서유럽
- 이름 정렬은 탐색기처럼 숫자 순서 (file2 → file10), 폴더는 항상 위
- 단축키: Ctrl+O 열기, Backspace 뒤로, Enter 열기

## 3. 우클릭 메뉴 (F10)

| 선택 | 메뉴 이름 (실제 탐색기에서 확인함) |
|---|---|
| 파일 하나 `01_기획서.md` | 또또집: 01_기획서.zip으로 압축(D) |
| 파일 두 개 (`qz` 폴더 안) | 또또집: qz.zip으로 압축(D) |
| 폴더 하나 `puzzle` | 또또집: puzzle.zip으로 압축(D) |

- 누르면 진행률 창만 뜨고, 끝나면 탐색기에서 새 ZIP 파일이 선택된 상태가 됨
- 같은 이름이 있으면 `docs (2).zip`
- 선택한 파일 목록은 임시 파일로 넘겨서 수천 개를 골라도 동작 (명령줄 길이 제한 없음)
- 윈도우 11 첫 메뉴에는 나오지 않고 "더 많은 옵션 표시"에만 나옴 (요청대로)
- DLL은 메뉴 글자와 프로그램 실행만 담당 → 탐색기가 멈추거나 꺼질 위험 최소화. Visual C++ 런타임 없이 동작
- 메뉴 이름: 반디집의 "○○.zip으로 압축하기(Z)"와 글자·단축키가 똑같으면 구분이 안 돼서 "또또집:" 머리말과 단축키 D를 씀 (임시, 정식 문구는 미정)

### 등록 방식: PC 전체(HKLM), 관리자 권한 필요
처음에는 현재 사용자(HKCU)에만 등록했는데 탐색기에 나오지 않았습니다. 조사 결과:

| 확인한 것 | 결과 |
|---|---|
| 다른 프로그램(PowerShell)에서 같은 방식으로 메뉴 만들기 | 또또집 메뉴 나옴 (등록 자체는 정상) |
| 탐색기가 또또집 DLL을 불렀는지 (진단 기록) | 한 번도 안 부름 |
| 보안 프로그램·코드 무결성 차단 기록 | 없음 |
| DLL 없이 메모장만 여는 단순 메뉴를 HKCU에 등록 | 탐색기에 안 나옴 |
| 탐색기 다시 시작 | 그래도 안 나옴 |
| 같은 내용을 PC 전체(HKLM)에 등록 | **바로 나옴** |

- 결론: 이 PC(윈도우 11 + StartAllBack)의 탐색기는 사용자별(HKCU) 우클릭 메뉴를 보여 주지 않음. 정확히 무엇이 막는지(윈도우 자체인지 StartAllBack인지)는 확인하지 못함
- 조치: 등록 기본값을 PC 전체로 변경 (`DdoddoZip.exe --register-shell`, 관리자 권한 필요. `--user`를 붙이면 현재 사용자만)
- 영향: **7단계 설치 파일은 관리자 권한으로 PC 전체에 설치하는 방식**으로 만들어야 함 (2단계 설계서 D5 "사용자 단위 설치"에서 변경)
- 그 밖에 등록 위치를 "모든 파일과 폴더(AllFilesystemObjects)" 하나에서 "파일(`*`)"과 "폴더(`Directory`)" 둘로 나누고, 잘 나오는 다른 프로그램처럼 기본 글자·아이콘·NeverDefault 값을 넣음

## 4. 개발 중 고친 문제
1. **대화상자가 열리지 않고 프로그램이 꺼짐**: 공통 스타일에 스타일로 지정할 수 없는 속성(창 시작 위치)이 있었음 → 각 창에서 직접 지정. 예상 못 한 오류가 나도 프로그램이 꺼지지 않도록 마지막 안전장치 추가
2. **창을 열자마자 첫 줄이 선택돼 보임** → 수정
3. **C++ 빌드 중간 파일이 작업 폴더에 생김** → 빌드 전용 폴더로 이동 (작업 폴더에 생긴 2개는 삭제함)

## 5. 3단계 설계와 달라진 점
- 암호 창의 "이번 작업에서 같은 암호 계속 쓰기" 체크 상자는 뺐습니다. 압축 파일을 열어 둔 동안에는 한 번 맞힌 암호를 자동으로 기억합니다.
- 덮어쓰기 창의 "(남은 충돌 4개)" 숫자는 미리 알 수 없어서 뺐습니다.
- 화면 구조는 설계서의 MVVM 도구(CommunityToolkit.Mvvm) 대신 기본 기능만으로 만들었습니다. 외부 의존성이 줄고 동작은 같습니다.

## 6. 알려진 제약 (다음 단계에서 다룸)
- **실행에 .NET 10 데스크톱 런타임 필요**: 개발 PC에는 있음. 7단계 설치 파일에서 함께 설치하거나 런타임을 포함한 배포로 해결
- **끌어 놓기로 꺼내기**: 64MB가 넘거나 암호가 있으면 먼저 진행률 창으로 임시 폴더에 푼 뒤 끌어 놓기가 시작됨. 마우스 버튼을 그 사이에 놓으면 다시 끌어야 함
- **압축 파일 열기 중 진행률 없음**: 아주 큰 TAR.GZ를 열 때는 마우스 커서만 바뀜
- **"새로 압축하기" 버튼은 파일만 고를 수 있음**: 폴더는 창에 끌어다 놓기
- **다크 모드, 파일 연결, 우클릭 메뉴 확장(압축 풀기: 여기에 풀기, ○○\ 에 풀기 등)**은 P1 (6단계)
- **DLL을 새로 설치해도 탐색기는 다시 시작하기 전까지 예전 DLL을 계속 씀** (개발 중에만 해당)

## 7. 직접 써 보는 방법
- 프로그램: 시작 메뉴 등록은 7단계에서. 지금은 `%LOCALAPPDATA%\Programs\DdoddoZip\DdoddoZip.exe` 실행
- 우클릭: 탐색기에서 파일 선택 → 우클릭 → 더 많은 옵션 표시 → "또또집: ○○.zip으로 압축(D)"
- 우클릭 메뉴 해제: `powershell -ExecutionPolicy Bypass -File tools\dev-install.ps1 -Uninstall`
