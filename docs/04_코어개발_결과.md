## 3. 자동 테스트 (55개 모두 통과)

| 분류 | 확인 내용 |
|---|---|
| 압축 후 풀기 | 6개 형식 각각 압축 → 풀기 → 원본과 내용(해시) 완전히 같음. 한글 이름, 빈 폴더, 빈 파일 포함 |
| 압축 수준 | ZIP 저장만/빠름/최고 |
| 이름 규칙 | 파일 하나·폴더 하나·여러 개 선택 시 이름, `docs (2).zip` 번호 붙이기 |
| 한글 이름 | 옛 CP949 ZIP 판별과 정상 해제, UTF-8 판별 |
| 보안 | `../../` 경로 차단하고 나머지 파일은 정상 해제 |
| 오류 | 압축 파일이 아닌 파일, 반쯤 잘린 파일, 데이터 손상 파일 → 프로그램이 꺼지지 않고 원인 안내 |
| 암호 | ZIP(AES-256), 7Z, 7Z(파일 이름까지 암호화): 틀린 암호 → 다시 물음 → 맞는 암호로 성공 |
| 덮어쓰기 | 덮어쓰기/건너뛰기/이름 바꾸기, "모두 적용" 시 한 번만 물음 |
| 취소 | 압축 취소 시 임시 파일 남지 않음, 해제 중 취소 동작 |

## 4. 개발 중 발견해서 고친 문제
1. **ZIP 여러 파일 압축 실패**: 7-Zip이 여러 파일을 동시에 압축하는데, 아직 읽는 파일을 먼저 닫아 버림 → 파일마다 다 읽은 뒤 닫고, 다시 필요하면 다시 여는 방식으로 수정
2. **TAR.XZ / TAR.BZ2 목록이 안 보임**: XZ·BZ2는 안에 든 파일 이름을 저장하지 않음 → 파일 확장자로 TAR를 알아보도록 수정
3. **`a:b.txt` 이름을 드라이브 경로로 오해** → 드라이브 문자 판단 규칙 수정

## 5. 알게 된 제약
- **ZIP 암호는 영문·숫자·기호만 가능** (7-Zip 엔진 제약). 한글 암호를 넣으면 "7Z 형식을 쓰세요" 안내. 7Z는 한글 암호 가능.
- **TAR.GZ 등은 임시 TAR 파일을 거침**: 열거나 만들 때 원본 크기만큼 임시 공간이 필요. 7단계 대용량 테스트 때 다시 점검.
- **RAR, ISO 해제는 자동 테스트 없음**: 만들 수 없는 형식이라 샘플 파일이 필요. 가지고 계신 RAR/ISO 파일로 확인하거나 7단계에서 샘플을 모아 테스트.

## 6. 직접 해 보는 방법

명령줄 도구 위치: `%LOCALAPPDATA%\DdoddoZip.build\bin\DdoddoZip.Cli\debug\ddz.exe`

```
ddz quickzip "C:\폴더\파일1.txt" "C:\폴더\파일2.txt"     → C:\폴더\폴더.zip
ddz l 자료.zip                                         목록 보기
ddz x 자료.zip -o D:\풀위치                             풀기
ddz a 백업.7z D:\문서 --level max -p 암호               압축하기
ddz t 자료.zip                                         검사
```
