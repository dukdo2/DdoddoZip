## 3. 화면별 구성

### S1 메인 창 (빈 상태)
- 가운데 큰 안내 영역: "압축할 파일이나 열 압축 파일을 여기에 끌어다 놓으세요"
- 버튼: [압축 파일 열기] [새로 압축하기]
- 아래: 최근에 연 압축 파일 5개

### S2 메인 창 (압축 파일 열림)
- **도구 모음**: 열기 / 풀기 / 여기에 풀기 / 압축하기 / 파일명 인코딩
- **주소 표시줄**: `파일이름.zip > 폴더 > 하위폴더`, 뒤로 가기·위로 가기
- **왼쪽 폴더 트리** (숨기기 가능) + **오른쪽 파일 목록**
- 목록 칸: 이름, 크기, 압축 크기, 종류, 수정한 날짜 (칸 제목 눌러 정렬)
- 목록에서 더블클릭: 폴더는 들어가기, 파일은 임시 폴더에 풀고 연결된 프로그램으로 열기
- 목록에서 바탕화면이나 탐색기로 끌어 놓기: 그 위치에 풀기
- **상태 표시줄**: 형식, 파일 수, 원래 크기 → 압축 크기(압축률), 파일명 인코딩(자동: CP949 등), 암호 여부

### S3 압축하기 창
- 압축 파일 이름, 저장 위치(찾아보기)
- 형식: ZIP / 7Z / TAR / TAR.GZ / TAR.XZ / TAR.BZ2
- 압축 수준: 저장만 / 빠름 / **보통(기본)** / 최고
- 암호, 분할 압축: 자리만 만들어 두고 P1에서 활성화 (첫 버전에서는 숨김)
- 하단: 담길 파일 수와 전체 크기, [압축] [취소]

### S4 풀기 창
- 풀 위치 (기본: 압축 파일이 있는 폴더)
- 체크: "압축 파일 이름으로 폴더 만들기" (기본 켬, 압축 파일 안에 폴더 하나만 있으면 자동으로 끔)
- 덮어쓰기 기본 동작: 물어보기(기본) / 모두 덮어쓰기 / 모두 건너뛰기 / 이름 바꾸기
- 체크: "다 풀고 폴더 열기"
- [풀기] [취소]

### S5 진행률 창
- 제목: "docs.zip 압축 중" / "자료.7z 푸는 중"
- 현재 파일 이름, 진행 막대(%), 처리한 크기 / 전체 크기, 속도, 남은 시간
- [취소] (누르면 "취소할까요?" 확인 → 만들던 압축 파일은 지움)
- 끝나면 자동으로 닫힘. 끝난 뒤 열기 옵션은 설정에서 고를 수 있음(기본: 닫기만)
- 작업 표시줄 아이콘에도 진행률 표시

### S6 암호 입력 창
- 파일 이름 표시, 암호 입력칸(보기 버튼), 체크: "이번 작업에서 같은 암호 계속 쓰기"
- 틀리면 같은 창에 "암호가 맞지 않습니다" 빨간 글자

### S7 덮어쓰기 확인 창
- "같은 이름의 파일이 이미 있습니다"
- 기존 파일 / 새 파일 각각 크기와 날짜 표시 (더 최신인 쪽 강조)
- [덮어쓰기] [건너뛰기] [이름 바꾸기] + 체크: "나머지 파일에도 모두 적용"

### S8 오류 안내 창
- 무엇이 문제인지 쉬운 말로 한 줄 + 해결 방법 한 줄
  - 예: "압축 파일이 손상되어 일부 파일을 풀 수 없습니다. 다시 내려받아 보세요."
- [자세히] 누르면 실패한 파일 목록과 기술 정보 (복사 가능)

### S9 탐색기 우클릭 메뉴
- 위치: "더 많은 옵션 표시" 메뉴의 "연결 프로그램" 근처
- 항목: 또또집 아이콘 + "**01_기획서.zip으로 압축하기(Z)**"
- 누르면 S5 진행률 창만 뜨고, 끝나면 같은 폴더에 ZIP이 생기며 그 파일이 선택된 상태가 됨

## 4. 주요 흐름

1. **우클릭 빠른 압축**: 파일 선택 → 우클릭 → 더 많은 옵션 표시 → "○○.zip으로 압축하기" → S5 → 완료(자동 닫힘)
2. **압축 파일 열어서 일부만 풀기**: 압축 파일 더블클릭 → (암호면 S6) → S2 → 파일 선택 → [풀기] → S4 → S5 → (같은 이름 있으면 S7) → 완료
3. **창에서 새로 압축**: S1에 파일 끌어다 놓기 → S3 → S5 → 완료

> 압축 파일 더블클릭으로 여는 것(파일 연결)은 P1(F12). 첫 버전은 프로그램에서 열기나 끌어다 놓기로 엽니다.

## 5. 승인 요청 사항
1. 대표 색(민트 `#12A38A`)과 전체 스타일
2. 메인 창 구성: 왼쪽 폴더 트리 + 오른쪽 목록
3. 진행률 창이 끝나면 자동으로 닫히는 동작
4. 각 창의 기본값 (압축 수준 "보통", "압축 파일 이름으로 폴더 만들기" 켬 등)
